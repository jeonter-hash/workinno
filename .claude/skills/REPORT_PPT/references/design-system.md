# KSA 모노톤 PPT 디자인 시스템 — 규범

발표용(PRESENT_PPT)과 보고서용(REPORT_PPT)이 **같은 프레임·같은 도식·같은 색**을 쓰고 **밀도만** 다르다.
이 문서는 두 스킬의 공통 규범이며, 값이 어긋나면 이 문서가 이긴다.

---

## 0. 판형과 서체

| 항목 | 값 |
|---|---|
| 판형 | **A4 가로만** — 10.8333" × 7.5" (9906000 × 6858000 EMU, 27.52 × 19.05cm). 16:9·4:3·A4 세로 요청은 거절하고 A4 가로로 제안 |
| 서체 | **맑은 고딕만** — Pretendard·HY계열·Noto 등 금지. Windows 기본 탑재라 임베드 불필요, 맑은 고딕이 없는 환경엔 PDF로 배포 |
| 굵기 | 맑은 고딕은 Semilight/Regular/Bold 3단뿐. 원 시스템의 6단 웨이트를 접어 쓰고 **접혀 사라진 대비는 크기와 색으로** 만든다 |
| 로고 | 한국표준협회 워드마크(`assets/ksa_logo.jpg`, 325×42). 높이 0.24"에 **원본 비율 자동**, 오른쪽 끝을 우측 0.5" 여백에 정렬. 배경 박스·밑줄·그림자·보정·크롭 금지 |

로고 원본은 흰 배경 JPEG(누끼 아님)이라 **흰 장표에서만 안전**하다. 어두운 배경 장표에 로고가 필요하면 흰 반전본을 받아 `logoWhite`로 넘긴다.

## 1. 색

무채색이 뼈대다.

```
ink  #111111   g1 #3A3A3A   g2 #6B6B6B   g3 #9E9E9E
g4   #C7C7C7   g5 #E4E4E4   g6 #F4F4F4   g7 #FAFAFA   w #FFFFFF
```

**보고서용(REPORT_PPT)은 무채색만 쓴다.** 표가 많아 색이 들어가면 산만해진다.

**발표용(PRESENT_PPT)은 여기에 두 색만 더한다**(`palette:'accent'`). KSA 로고에서 뽑은 값이다.

| 색 | 값 | 쓰는 곳 |
|---|---|---|
| 구조색 네이비 | `#1F3864` (중간 `#4A6491`) | 표 머리글·체브론 진행 단계·트리 루트·간트 막대·조직도 최상위·3단 계층 |
| 강조색 레드 | `#C4303C` | **장표당 한 곳만** — 핵심 KPI 1장·워터폴 목표·현재 단계·매트릭스 우선 영역·마일스톤·표지 먹 패널 |

- 이 다섯 값 밖의 유채색은 쓰지 않는다. 강조는 ①먹칠 대 회색칠 ②굵기 ③크기 ④헤어라인으로 만든다.
- **흰 배경 위 글자는 `#6B6B6B`보다 흐릴 수 없다.** `#C7C7C7` 글자는 결함이다. 어두운 배경 위의 밝은 회색은 대비가 충분하므로 예외.
- `#9E9E9E`는 "해당 없음(—)" 기호 등 최소 용도로만.

## 2. 5존 (전 장표 고정)

헤드는 **타이틀**과 **메시지** 두 줄기로 나뉜다. 좌표는 렌더 실측으로 잡았고 **타이틀↔메시지 = 메시지↔본문 = 0.14"**로 같다. 메시지 상자는 2줄분으로 고정해 한 줄이어도 본문 시작선이 올라오지 않는다. 문법은 `references/headline.md`.

| 존 | 발표용 | 보고서용 |
|---|---|---|
| 챕터 | 0.40" | 0.40" |
| 헤어라인 | 0.82" | 0.82" |
| 타이틀 | 0.94" · 24pt Bold | 0.94" · 20pt Bold |
| 메시지 | 1.43" · 13pt · 상자 0.62" | 1.37" · 12pt · 상자 0.58" |
| 본문 | 2.11"–6.85" | 2.00"–6.85" |
| 푸터 | 7.05" | 7.05" |


| 존 | x | y | w | h |
|---|---|---|---|---|
| 챕터명 | 0.5 | **0.40** | 6.2 | 0.30 |
| 헤더 구분선 | 0.5 | 0.82 | 9.8333 | — |
| 로고 | 자동 | 0.44 | 자동 | 0.24 |
| 헤드라인 | 0.5 | **1.00** | 9.8333 | 0.75 |
| 부제 | 0.5 | **1.63** | 9.8333 | 0.40 |
| **본문** | 0.5 | **2.20** | 9.8333 | **4.65** |
| 클리어런스 | — | 6.85 | — | 0.20 (비움) |
| 푸터 | 0.5 | **7.05** | 9.8333 | 0.25 |

**본문 상·하한 2.20"–6.85"는 벽이다.** 넘치면 내용을 줄이거나 장표를 나눈다. 헬퍼가 예외를 던져 생성을 막는다.
표지·섹션 디바이더·클로징만 프레임을 의도적으로 깰 수 있다.

## 3. 밀도 — 두 모드

| 항목 | 발표용 present | 보고서용 report |
|---|---|---|
| 챕터명 | 14pt Bold | 12pt Bold |
| 헤드라인 | **24pt** Bold | **20pt** Bold |
| 부제 | 13pt | 11.5pt |
| 본문 소제목 | 14pt Bold | 12pt Bold |
| 본문 | 11.5pt | 9.5pt |
| 작은 글 | 10pt | 9pt |
| 캡션·출처 | 9.5pt | 9pt |
| KPI 숫자 | 34pt | 24pt |
| 표 행 높이 | 0.44" | 0.335" (dense 0.295") |
| 카드 패딩 | 0.17" | 0.12" |
| 최소 글자 | **9.5pt** | **9pt** (dense 8.5pt — 절대 하한) |

발표용은 한 장에 메시지 하나와 도식 하나, 보고서용은 표와 각주로 근거까지 담는다.

**보고서용 `dense`** — 20행짜리 표처럼 내용이 많을 때만 쓴다(`createDeck({mode:'report', dense:true})`). 본문 9pt·행 0.295"로 한 장 수용량이 11행 → 13행(+18%)이 된다. 평소에는 기본값을 쓴다 — 지금 밀도에서 공간이 모자란 경우는 드물고, 글자만 줄이면 여백이 늘어 오히려 빈약해진다. **8.5pt 아래로는 내려가지 않는다.**

## 4. 12열 그리드

- 콘텐츠 폭 9.8333", 거터 0.2" → **1열 = 0.63611"**, 열 간격 0.83611"
- `cx(i) = 0.5 + i × 0.83611`, `cw(n) = n × 0.63611 + (n−1) × 0.2`
- 균등 분할(오른쪽 끝은 항상 10.3333"): 2-up 4.8166 / 3-up 3.1444 / 4-up 2.3083

## 5. 표

- **데이터 성격의 표는 네이티브(`tableNative`)** — PowerPoint 진짜 표. 행 추가·삭제·정렬·셀 병합이 되고, 글이 길면 행 높이가 자동으로 늘어난다.
- 도식과 x좌표를 정밀하게 맞춰야 하는 표만 도형(`table`)으로 남긴다.
- **표 머리글은 항상 가운데 정렬**, 먹 배경에 흰 글자.
- **셀 윤곽선을 그리지 않는다.** 머리글 먹 밴드 + 교차 음영(`#FAFAFA`) + 표 하단 마감선 하나로 끝낸다.
- 네이티브 표는 글이 길면 아래로 자란다. 헬퍼가 줄 수를 미리 추정해 벽(6.85")을 넘으면 생성을 중단한다.

## 6. 선과 글자

- **밑줄은 위 글자의 실제 폭에 맞춘다.** 임의 길이 금지 — `textW()`로 계산한다.
- **선은 글자를 침범하지 않는다.** 축 라벨 → 0.09" → 구분선 → 0.06" → 캡션 순으로 쌓는다.
- `line: { width: 0 }`을 **절대 쓰지 않는다.** pptxgenjs가 이를 무시하고 1pt `#333333` 선을 그린다. 선을 없애려면 `line: { type: 'none' }`.

## 7. 문안 — 정중한 개조식

- 헤드라인은 명사형 종결. "…나왔다"(X) → "…에 집중"(O)
- 단정·하대 표현을 피하고 권고·유보·필요로 맺는다. "올해 하지 않는다"(X) → "당해연도 추진 유보"(O)
- 부제는 헤드라인의 근거를 한 줄로. 캡션·각주도 같은 어조.
- 이모지 금지.

## 8. 표지·목차·마스터

- **표지** — **사진 표지.** 상단에 사진 4장을 사선으로 나눈 띠(y 0.12–2.73"), 좌하단 먹 패널에 기관명 14pt·제목 26pt·구분선·일자·수행기관, 우하단에 대형 사진. **로고를 넣지 않고, 목차도 넣지 않는다.**
  먹 패널은 무채색이면 `#3A3A3A`, 강조 팔레트면 네이비 `#1F3864`. 사진 5장은 각각 독립된 그림 도형이라 PowerPoint에서 [그림 바꾸기]로 갈아끼워도 사선이 유지된다. 사진을 주지 않으면 자리표시로 출고된다.
  사선은 후처리(`postprocess.py`)가 띠 사진의 도형을 평행사변형으로 바꿔 만든다.
  사진은 고객사 제공본을 우선하고, 웹 이미지는 공공누리 1유형·CC0/CC-BY(출처 표기)만 쓴다.
  사진을 쓰지 않을 때만 격자 도형 표지(`coverPlain`)를 쓴다.
- **목차** — 본문 장표 프레임을 쓰고 좌상단 챕터명은 비운다. '목차'는 헤드라인에 한 번만. 장 제목·세부 항목·점선 리더·우측 정렬 쪽번호.
- **슬라이드 마스터** — 본문 마스터(`KSA_BODY`)가 헤더 헤어라인, **우측 상단 문서 제목**, **하단 가운데 자동 슬라이드 번호**(`<a:fld type="slidenum">`)를 그린다. 문서 제목은 [보기 → 슬라이드 마스터]에서 한 번 고치면 전 장표에 반영된다. 표지·간지는 번호 없는 `KSA_TITLE` 마스터를 쓴다.
- **출처**는 푸터가 아니라 해당 도식·표 바로 아래에 붙인다(`source()`).

## 9. 차트

| 항목 | 값 |
|---|---|
| 계열 색 | 명도 계열 `dark → mid → #9E9E9E → #C7C7C7 → #E4E4E4`. **5개까지** |
| 격자선 | 그리지 않는다 |
| 값 표기 | 데이터 레이블로 직접. 막대·원은 값 축을 숨긴다 |
| 축선 | `#C7C7C7` 헤어라인. 축 글자는 cap 크기 `#6B6B6B` |
| 범례 | 계열이 하나면 두지 않는다. 원 차트는 오른쪽, 나머지는 아래 |
| 원 차트 레이블 | 조각 **바깥**. 먹 조각 위에서는 글자가 묻힌다 |

색을 쓰지 않으므로 **계열이 다섯을 넘으면 읽을 수 없다.** 묶거나 차트를 나눈다.

## 10. 도식 어휘

| 의미 | 도식 | 규격 |
|---|---|---|
| 집합·공통 | 벤 | 원 3개, 투명도 80%로 겹쳐 교집합이 진해진다. 이름은 원 바깥 |
| 중심과 요소 | 허브&스포크 | 허브는 먹 채움 + 흰 글자, 위성은 `#F4F4F4` + 헤어라인 |
| 주기 | 순환 | 단계는 원, 이웃 사이는 `#C7C7C7` 화살표. 강조 단계만 먹 반전 |
| 계층 | 피라미드 | 위→아래로 `dark → #6B6B6B → #9E9E9E → …`. 글자색은 배경 명도로 결정 |
| 성장 | 계단 | 왼→오른쪽으로 높아지고 진해진다. 마지막 단이 가장 진하다 |
| 정성 비교 | 하비볼 | **명도가 아니라 채운 몫**으로 5단계. 0·1/4·1/2·3/4·1 |
| 전후 관계 | 원인→결과 | 왼쪽 흰 박스(현상) → 화살표 → 오른쪽 `#FAFAFA` 박스(결과, 굵게) |

**밝은 회색 배경에 흰 글자를 얹지 않는다.** `onTone()`이 배경 명도를 보고 글자색을 고른다.
그라데이션·3D·베벨은 쓰지 않는다.

## 11. 표현의 비중

한 장표에 표만 있으면 그 장표는 아직 주장을 하지 않은 것이다.
**표가 본문 높이의 65%를 넘게 차지하고 차트도 없으면 점검기가 경고한다.**
표 위에 도식이나 차트로 그림을 먼저 보이고, 표는 그 아래에서 값을 확인하는 자리에 둔다.
무엇을 말하려는지에서 표현을 고르는 기준은 `references/diagrams.md`.

## 12. 내보내기

- 맑은 고딕은 임베드 불필요. 없는 환경(macOS·리눅스)에는 서체를 바꾸지 말고 PDF로.
- 차트·표 텍스트는 살아 있는 텍스트로 둔다(이미지로 굽지 않는다).
- `postprocess.py`는 필수 — 미실행 시 PowerPoint가 파일을 손상으로 판단한다(§ 스킬 문서 참조).
