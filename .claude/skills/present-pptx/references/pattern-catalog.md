## P1. 표지
- **용도**: 발표 덱 1장. 배경(네이비 스우시 + 도시·인물 사진)은 slideLayout4 소속이라 텍스트·로고만 교체하면 된다.
- **구성**: 좌상단 발주기관 로고 → 좌중단 발표 제목 → 수행기관명 → 날짜.
- **부품**: 로고 pic (1.7,1.11 5.65×1.68) — 발주기관 CI로 교체(비율 유지, 좌상단 흰 영역 안). 제목 TextBox (1.37,6.94 16.27×2.95) 32pt 검정 major폰트(맑은 고딕), 좌정렬. 수행기관명 (1.37,11.72) 20pt 굵게 #002060. 날짜 (1.37,13.27) 18pt 굵게 검정 "YYYY. MM. DD." 형식.
- **가감·교체**: 텍스트 3개 + 로고 1개만. 부제가 필요하면 제목 박스 안 둘째 문단(작은 크기)으로.
- **주의**: 제목은 **2줄 이내**. 원본은 3줄이 되어 수행기관명과 겹쳐 있다(그대로 두지 말 것). 흰 스우시 영역(좌측 ~60%) 밖으로 텍스트가 나가면 사진과 겹쳐 안 읽힌다.

## P2. 목차
- **용도**: 발표 덱 2장. 배경(회색 웨지 삼각형 + 수평선 2개)은 slideLayout5 소속.
- **구성**: 본문 플레이스홀더 (1.96,5.78 24.77×11.47)에 번호 리스트.
- **부품**: 항목당 한 문단, `N.` + 탭 + 항목명, 18pt 검정 굵게, 줄 간격 넉넉(원본 5항목). 항목명은 브레드크럼의 대목차와 문구를 일치시킨다.
- **가감·교체**: 문단 가감만. 3~7항목 권장. 8항목 이상이면 크기를 줄이지 말고 대목차를 묶어라.
- **주의**: 배경 수평선 y5.4 아래부터 본문 존이다. 항목이 적으면 위쪽부터 채우고 아래 여백을 남긴다(중앙 배치하지 않음).

## P5. 성과표 → 대형 화살표 → 요인 카드 도출 흐름(좌 근거표·우 5행 라벨+설명 카드)

## P14. 3열 삼분할 — Before/After 전환 + 단계 스택 프로세스 + 게이트 검증 표(체계·프로세스·품질)

- **용도**: 거점·조직 구조(계층 조직도)와 거점별 특화 내용(카드군)을 상단에 병렬로 놓고, 그 아래 전체를 관통하는 프로세스 흐름과 기대효과를 전폭으로 펼칠 때. 네트워크·생태계·거버넌스류 장표에 범용.
- **구성**: 본문 존을 3단 구성. 상단(y≈5.5~11.0): 좌 패널(5D6DBE 헤더 '12개 지역본부 기반 네트워킹 구조'+흰 본문면)에 본부→지역본부→4개 협력주체 박스의 2계층 조직도(꺾인 연결선), 우 패널(58A7AE 헤더 '지역별 산업 특화 네트워킹'+흰 본문면)에 지역 카드 4개(EEF6F7)+각 카드 아래 파트너 박스 4개(무채움 테두리)를 수직선으로 연결. 중단(y≈11.2~13.5): 체크아이콘 소제목 '선순환 지원 생태계: 발굴→진단→훈련 연계' 아래 흰 카드 7개를 화살표 6개로 잇는 전폭 수평 체인. 하단(y≈13.8~16.3): 체크아이콘 소제목 '네트워킹 활용의 5가지 효과' 아래 무채움 테두리 카드 5개 열.
- **부품**: 좌 패널 그룹(슬라이드 기준 1.2,5.46 12.36×5.59): 헤더 round2SameRect 5D6DBE 10pt 굵게 흰색 + 본문면 흰색(자식좌표 5.05폭이 그룹폭 12.36으로 스케일됨). 조직도 그룹(2.03,6.39 10.61×4.34) 내부(자식좌표계): KSA박스 (3.32,6.15 5.98×0.57) 흰색 10pt 굵게, 지역본부박스 (3.32,6.95 5.98×0.7), 협력주체 박스 4개 (x=1.43/3.9/6.38/8.85, y=8.38, 각 2.23×2.6) DFE2F2 9pt '제목+└ 3줄', bentConnector3 4개(rot 90/270+flip 조합) 검정 0.5pt. 우 패널 그룹(13.96,5.46 12.36×5.59): 헤더 58A7AE + 본문면. 지역카드 4개(자식좌표 x=13.17/15.64/18.12/20.59, y=6.51, 각 2.23×2.2) EEF6F7, 제목 9pt 굵게 '여수: 석유화학'+└ 4줄 9pt. 파트너박스 4개(같은 x, 자식 y=5.72, 각 2.23×2.41) 무채움+hairline, • 9pt 4줄. 수직 연결선 4개(x=14.81/18.02/21.23/24.43, y=8.55, h0.2~0.82) 검정 0.5pt. 중단 소제목 그룹(1.2,11.19 9.48×0.71): pic 0.47cm+10.5pt 굵게. 체인 그룹(1.67,12.05 24.66×1.46): 흰 카드 7개(자식 x=1.59부터 간격 3.84, 각 3.2×1.28) hairline, 9pt 굵게 중앙 1~2줄. 화살표 cxnSp 6개(슬라이드 기준 x=4.68/8.28/11.89/15.5/19.11/22.71, y=12.78, w0.6) 회색 0.5pt. 하단 소제목 그룹(1.2,13.76 9.48×0.71). 효과카드 그룹(1.67,14.55 24.66×1.72): 무채움 카드 5개(자식 x=1.67부터 간격 3.605, 각 3.01×1.64), 제목 9pt 굵게 1040C3 '①…↑'+설명 9pt 중앙.
- **가감·교체**: 조직도 계층명(본부/거점)+협력주체 4박스, 지역카드 4개(지역:산업+특화 4줄)+파트너 4박스, 체인 카드 7개, 효과 카드 5개 텍스트를 교체. 지역 4→3개: 카드+파트너박스+수직선 1세트 삭제 후 자식 x 간격 2.47→3.3으로 재배분. 체인 7→5단: 카드 2개+화살표 2개 삭제 후 간격 3.84→5.4로 재배분(화살표는 슬라이드 레벨이라 별도 이동). 효과 5→4개: 카드 1개 삭제 후 간격 3.605→4.55 재배분. 좌 조직도가 불필요하면 좌 패널 그룹 통째 삭제 후 우 패널을 폭 25.1로 확장.
- **주의**: 이 장표는 chOff 스케일이 가장 심함: 좌 패널 그룹은 자식 폭 5.05가 그룹 폭 12.36으로 약 2.45배 수평 확대되고, 체인 그룹(자식 스팬 26.2→24.66)·효과 그룹(자식 스팬 17.4→24.66, 약 1.41배)도 스케일 적용 — 그룹 내부 개별 이동 대신 그룹 해제 후 재배치하거나 그룹 xfrm만 조작할 것. 우 패널은 그룹 79 안에 그룹 54가 중첩된 2중 그룹. 조직도의 bentConnector3 4개는 rot=90/270+flipH/V 조합의 자식좌표라 재현이 까다로움 — LibreOffice 렌더에서 파트너 박스 위 대각선 아티팩트로 보임. 체인 화살표 6개는 그룹 밖 슬라이드 절대좌표(y=12.78) — 체인 카드 재배분 시 함께 수동 이동. 카드 폭 3.2에 9pt 2줄(약 22자) 한계 — '지역 훈련기관(폴리텍·대학·민간) 맞춤과정 개설'처럼 긴 항목은 오버플로 직전. 체크아이콘 pic 2개는 그룹 내 chOff 좌표(1.24,6.09)로 기록됨.

## P30. 2×2 쿼드런트: 3열 단계 로드맵 + 채널 2분할 + 소스→가공 흐름 + 체크 요약 박스
- **원본 예시**: 헤드라인: "참여기업 성공 스토리(E35740) 중심의 3단계 홍보 전략(5D6DBE) : 우수사례 기반 신뢰도 검증 및 참여 동기 강화" / 라벨: "언론홍보"
- **용도**: 시기별 단계 로드맵·채널 구분·핵심 전략 메커니즘·요점 정리를 한 장에 압축할 때. 홍보·확산·커뮤니케이션 계획뿐 아니라 '단계+수단+원리+요약' 4분면이 필요한 실행계획 장표에 범용.
- **구성**: 본문 존을 좌우 각 12.3폭의 2×2 쿼드런트로 분할, 각 분면은 1040C3 티저밴드+F2F2F2 백킹패널(테두리 없음) 세트가 감쌈. 좌상 '3단계 홍보 로드맵': 백킹 위에 [5D6DBE 헤더 'N단계(월)' + 흰 본문(1040C3 키워드 제목+└ 항목)] 칼럼 3개 병치. 우상 '우수사례 선정 및 OSMU 콘텐츠 전략': 좌측에 선정기준 흰 박스→[아래화살표]→58A7AE 결론박스 수직 흐름, 우측에 5D6DBE 헤더+1040C3 콜아웃(1개 사례→가공→다중 채널)+• 채널 목록 박스. 좌하 '온·오프라인 통합 미디어 믹스': [5D6DBE 헤더+흰 본문] 채널 카드 2개(온라인/오프라인) 병치. 우하: 티저밴드 없이 굵은 반투명 5D6DBE 테두리 roundRect 요약박스(✓ 5줄)+우측 홍보물 이미지.
- **부품**: 쿼드런트 밴드·백킹(공통): 밴드 round2SameRect 1040C3 12.31×0.7, 10pt 굵게 흰색 중앙, line none + 백킹 round2SameRect F2F2F2(bg1 lumMod95) 12.34폭, line none. 좌상 세트 (1.07~1.1, 5.7/6.4, 백킹 h4.96); 좌하 세트 (1.1,11.55 그룹, 밴드+백킹 h3.92); 우상 밴드 (14.1,5.7 12.31×0.7)+백킹 (14.07,6.4 12.34×4.96). 좌상 내부 그룹(1.47,6.87 11.56×4.06): 단계 칼럼 3개 — 헤더 5D6DBE (x=1.48/5.43/9.35, y≈6.84, 3.63~3.69×0.7) 10pt 굵게 흰색 '1단계 (3~4월)' + 본문 흰색 (같은 x, y≈7.54, ×2.66) 제목 10pt 굵게 1040C3+└ 10pt. 우상 내부: 선정기준 박스 (14.47,6.64 3.71×2.37) 흰색 10pt 5줄; 아래화살표 Freeform (16.06,9.05 0.52×0.53 rot90 flipH) scheme:bg2(lumMod=25000); 결론박스 (14.47,9.66 3.71×1.28) 58A7AE 10pt 굵게 흰색; OSMU 헤더 (18.57,6.64 7.48×0.76) 5D6DBE; 콜아웃 (18.57,7.4 7.48×1.3) 흰색 10pt 굵게 1040C3 중앙 2줄; 채널목록 (18.57,8.88 7.48×2.05) 흰색 • 9pt 4줄. 좌하 내부: 채널 카드 2개 — 헤더 (1.4/7.52, 12.73, 5.51×0.63) 5D6DBE + 본문 (1.4/7.52, 13.36, 5.51×2.45) 흰색 └ 10pt 4항목. 우하: roundRect (14.1,11.84 12.18×4.28) 흰색 채움 + 5D6DBE 40% 불투명 4.5pt 테두리, ✓ 10pt 굵게 5줄 + pic (22.51,12.41 3.26×3.26).
- **가감·교체**: 밴드 4개 제목, 단계 칼럼 3개(헤더 시기+제목+└ 2~4줄), 선정기준 5줄·결론박스 1문장, OSMU 콜아웃·채널 4불릿, 채널 카드 2개 └ 항목, ✓ 5줄을 교체. 단계 3→4열: 칼럼 세트 복제 후 폭 3.69→2.72, x=1.48/4.4/7.32/10.24 재배분. ✓ 5→4줄: 텍스트 줄만 삭제(박스 h 유지). 우하 이미지는 콘텐츠 종속 pic이므로 새 이미지로 교체하거나 삭제 후 요약박스 폭 12.18을 그대로 텍스트 전용화. 채널 2→3분할: 카드 폭 5.51→3.6, x=1.4/5.44/9.48 재배분.
