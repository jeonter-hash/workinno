# 금지 사전과 교체표

`SKILL.md` §2 문안 언어 계약의 세부. 순서는 실제로 자주 어기는 순.

## 1. 제작 용어의 문안 유출 (최다)

산출물 문안에 나오면 독자가 **AI가 자기 작업을 설명하는 소리**로 읽는다.

| 나오면 안 되는 표현 | 왜 |
|---|---|
| 프레임장 · 적용장 · 소결장 · 배치 단위 · 상향 링크 | 제작 지시용 용어 |
| 「모든 절은 4대 기준 중 하나 이상을 판정 기준으로 선언하고…」 | 규칙 자체를 문안에 옮김 |
| 읽는 경로 · 독자별 · 만으로 판단할 수 있 | 독자 안내 |
| 본 보고서는 3부로 구성 · 본문 N장 · 수록 장 | 보고서 자칭 |
| (4장 참조) · 4장에서 확인 · 근거 ①(4장) | 장번호 인용 |
| 표준 서식으로 기술 · 템플릿에 따라 · 같은 서식으로 제시 | 작성 자기지시 |
| 체계적으로 구성 · 논리적으로 구성 · 짜임새 있게 | 자기평가 |
| 결정 요청 · 의사결정 안건 · 기관 결정: ___ | 컨설팅 산출물의 형태가 아님 |

## 2. 학술·정책연구 보고서 용어

| 쓰지 않음 | 쓴다 | 비고 |
|---|---|---|
| **소결** | **종합** | 절 마무리 |
| (부 마무리도 소결) | **결론** | 부 마무리 — 절과 이름을 달리해 층위를 가름 |
| 접다 · 접는 규칙 · 기능 접기 | 통합 · 통합 기준 · 핵심 기능 도출 기준 | |

## 3. 문어체·구어체·비유 서술어

| 쓰지 않음 | 쓴다 |
|---|---|
| 세 갈래 / 네 갈래 / 두 갈래 | 3대 / 4대 · 세 가지 / 네 가지 · 두 축 |
| ~에서 밀림 | ~에서 뒤처짐 |
| A에 B를 얹다 | A에 B를 대응시키다 |
| ~에 닿다 / 닿지 않다 | ~로 이어지다 / 미치다 |
| 갈리다 / 갈려 | 나뉘다 / 달라지다 / 다르다 |
| 굳어지다 | 고착되다 |
| 뼈대 | 틀 |
| ~하기 이름(이르다) | ~하기에는 이른 단계 |

**「엇갈리다」는 표준어이므로 쓴다.** 점검기 정규식도 `(?<!엇)갈림`으로 제외한다.

## 4. 수사 표기

경계선은 **세는 행위가 있느냐**다. 값은 숫자로, 이름은 말로 쓴다.

| 구분 | 규칙 | 예 |
|---|---|---|
| 기간·연차 | 반드시 한자어 | 석 달 → **3개월** / 한 해 → **1년** / 세 해 잇달아 → **3개년 연속** |
| 단위 명사(건·개·명·점·팀·곳·회) | 아라비아 숫자 | 네 건 → **4건** / 스물두 건 → **22건** / 세 곳 → **3곳** / 두 팀 → **2개 팀** |
| 6 이상 | 아라비아 숫자 + 단위 | 여섯 영역 → **6개 영역** / 여덟 기능 → **8개 기능** / 열두 과제 → **12개 과제** |
| 1~5 순수 관형사 | 순우리말 허용 | 네 축 · 세 기준 · 두 가지 · 네 가지 |
| 묶음 명칭 | 「N대 ○○」 | 3대 공백 · 4대 판단기준 · 4대 전환 유형 |
| 맞춤법 | 첫 해 → **첫해**(또는 1차년도) | |

## 5. 유지 판정 — 바꾸지 않는 말

- **공백** — 「규정 공백·제도 공백·정책 공백」은 공공 문서의 표준 표현이고 "있어야 할 것이 없다"는 진단을 한 단어로 담는다. 「미비」로 바꾸면 정도의 문제가 되어 진단의 성격이 흐려진다.
- **네 축 · 세 기준 · 두 가지** — 단위 없이 명사를 직접 수식하는 자리. 「4개 축」으로 바꾸면 오히려 딱딱해진다.
- **엇갈리다 · 고착 · 정합 · 대응** — 한자어 명사형 계열은 그대로 쓴다.

## 6. 제목·머리글 어미 규칙 ★ 낱말 교체로는 잡히지 않는 유형

**표 머리글과 패널 제목은 항목의 이름이지 문장이 아니다. 반드시 명사구로 끝난다.**

| 금지 어미 | 예 | 바꿈 |
|---|---|---|
| **~것** | 확인한 것 / 마련한 것 / 확정된 것 / 아직 정해지지 않은 것 / 손에 쥐어야 할 것 | 진단 결과 / 개선 방안 / 확정 사항 / 미확정 사항 / 필수 산출물 |
| **~는가** | 무엇을 적는가 / 무엇을 고치는가 / 무엇을 맞추는가 | 기술 내용 / 개선 대상 / 정합 대상 |
| **~으면 · ~면 생기는 일** | 그것이 없으면 / 적지 않으면 생기는 일 | 미확보 시 영향 / 누락 시 영향 |
| **~이유** | 규정이 먼저인 이유 / 점검을 가볍게 두는 이유 | 규정 선행 근거 / 점검 부담 최소화 근거 |
| **~부분 · ~곳 · ~지점** | 설계가 미치지 않는 부분 / 관여가 몰리는 곳 / 네 결함이 만나는 지점 | 과업 범위 밖 영역 / 관여 집중 부서 / 4대 결함의 접점 |
| **서술문** | 상위 3층은 손대지 않는다 / 정비 총량은 합의대로 | 상위 3층 유지 / 정비 총량 합의 사항 |
| **늘어진 관형절** | 판정에 쓴 근거 / 집계에 쓰는 기록 / 부서가 든 폐지 사유 | 판정 근거 / 집계 자료 / 부서 폐지 사유 |

**허용** — 관형절이 붙어도 **명사구로 끝나면** 된다: 확인된 사실 · 다음 단계에 미치는 영향 · 남은 위상 과제 · 운영이 멈춘 채널 · 고착되는 위험.

검출: `것$|는가$|으면$|이유$|곳$|부분$|지점$|모습$|쓰임$` 를 `head:[...]` 와 `title:'...'` 에만 적용한다.

## 7. 「설계」의 용법

**금지어가 아니다. 목적어가 있느냐로 갈린다.**

| 적합 — 대상이 붙은 「~ 설계」 | 부적합 — 홀로 쓰여 산출물 전체를 가리킴 |
|---|---|
| 제도 설계 · 지표 설계 · 산식 재설계 · 양성 경로 설계 · 보상 설계 · 실태조사 설계 | 설계 결론 · 설계 요약 · 설계 내용 · 설계 영역 · 설계 범위 · 설계는 갖추어졌으므로 |

**바꾸는 이유 둘**
1. **과업명과 어긋난다.** 과업명이 「~ 재수립 및 ~ 고도화」인데 산출물을 「설계」라 부르면 다른 과업을 말하는 것처럼 읽힌다.
2. **「설계」는 엔지니어링·건축의 말이다.** 설계 다음에 시공이 온다. 컨설팅은 산출물이 **개선 방안**이고 다음에 오는 것이 **이행**이다.

| 홀로 쓰인 설계 | 바꿈 |
|---|---|
| 설계 결론 | **과업 결론** |
| 설계 요약 | **개선 방안 요약** |
| 설계 내용 (머리글) | **개선 방안** |
| 설계 영역 / 설계 축 | 개선 영역 / 개선 축 |
| 설계 범위 (밖) | **과업 범위** (밖) |
| 이어지는 설계 / 후속 설계 | 이어지는 과제 / **후속 과제** |
| 설계가 문서로만 남고 | 개선 방안이 문서로만 남고 |
