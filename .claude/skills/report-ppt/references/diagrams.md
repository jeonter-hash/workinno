# 도식·차트 선택 지침

장표를 만들 때 **먼저 "무엇을 말하려는가"를 정하고, 그다음 표현을 고른다.**
순서를 뒤집으면 표가 늘어난다. 표는 값을 정확히 읽혀야 할 때 쓰는 마지막 수단이다.

## 1. 세 갈래로 나뉜다

| 말하려는 것이 | 쓰는 것 |
|---|---|
| **관계·구조·흐름** — 무엇이 무엇을 낳는가, 무엇이 무엇을 받치는가 | **도식** |
| **크기·추세·구성비** — 얼마나 크고, 어디로 가고, 어떻게 나뉘는가 | **차트** |
| **값 자체** — 정확히 몇이고 누가 언제까지인가 | **표** |

한 장표에 표만 있으면 그 장표는 아직 아무 주장도 하지 않은 것이다.
점검기가 표만 있는 장표가 절반을 넘으면 경고한다.

## 2. 의미 → 표현

### 흐름과 절차

| 의미 | 표현 | 호출 |
|---|---|---|
| 단계가 순서대로 진행 | 체브론 | `chevrons` |
| 앞 단계 산출물이 다음 입력 | 체브론 + 게이트 표 | `chevrons` + `tableNative` |
| 반복되는 주기 | 순환 고리 | `cycle` |
| 12개월 일정 | 간트 | `gantt` |
| 단계마다 수준이 올라감 | 계단 | `steps` |

### 인과와 논리

| 의미 | 표현 | 호출 |
|---|---|---|
| 현상이 결과로 이어짐 | 원인→결과 | `causeEffect` |
| 하나가 여러 갈래로 나뉨 | 드라이버 트리 | `tree` |
| 여러 요소가 하나로 모임 | 허브&스포크 | `hubSpoke` |
| 총량이 항목별로 늘고 줄어 목표에 닿음 | 워터폴 | `waterfall` |

### 구조와 관계

| 의미 | 표현 | 호출 |
|---|---|---|
| 아래가 위를 받침 | 피라미드 | `pyramid` |
| 3단 체계 | 층 | `layers` |
| 공통분모·교집합 | 벤 | `venn` |
| 조직과 역할 | 조직도 도형 + 표 | 도형 + `tableNative` |

### 판단과 비교

| 의미 | 표현 | 호출 |
|---|---|---|
| 두 축으로 우선순위 판단 | 2×2 매트릭스 | `matrix` |
| 대안 3개 이상의 정성 비교 | 하비볼 평가표 | `harvey` |
| 핵심 지표 3–4개 | KPI 스트립 | `kpiRow` |

### 수치

| 의미 | 표현 | 호출 |
|---|---|---|
| 항목 간 크기 비교 (이름 짧고 5개 이하) | 세로막대 | `barChart` |
| 순위 (이름 길거나 6개 이상) | 가로막대 | `barChart({horizontal:true})` |
| 계획 대비 실적 | 2계열 막대 | `barChart({series})` |
| 시간에 따른 추세 | 선 | `lineChart` |
| 구성비 (조각 5개 이하) | 원·도넛 | `pieChart` |
| 규모와 비율을 함께 | 혼합 | `comboChart({rightAxis:true})` |

## 3. 표를 쓰는 자리

표가 맞는 것은 다음뿐이다.

- **정의서·명세서** — 과제·지표·산출물의 이름·담당·기간·산식
- **기준표** — 게이트 통과 기준, 판정 기준
- **원자료** — 값을 하나씩 확인해야 하는 집계

그래도 **표는 장표의 절반을 넘기지 않는다.** 표 위에 도식이나 차트로 그림을 먼저 보이고,
표는 그 아래에서 값을 확인하는 자리에 둔다.

## 4. 흔한 잘못과 고침

| 이렇게 하고 있으면 | 이렇게 바꾼다 |
|---|---|
| 12행 표로 업무별 시간을 늘어놓음 | **가로막대**로 상위 항목 순위를 보이고, 합계만 표로 |
| 6행 표로 과제 목록을 늘어놓음 | **허브&스포크**로 공통 전제를 보이고, 상세만 표로 |
| 8행 표로 지표를 늘어놓음 | **선 차트**로 추세를 보이고, 정의만 표로 |
| 매 장표 하단에 표를 하나씩 | 장표마다 표현을 바꾼다 — 도식·차트·표를 번갈아 |
| 표에 서술문을 채움 | 서술은 헤드 메시지로 올리고, 표에는 값과 짧은 명사구만 |

## 5. 무채색 제약

색이 없으므로 표현마다 한계가 있다.

- **차트 계열은 5개까지.** 여섯 번째부터 명도로 구분되지 않는다
- **원 차트 조각도 5개까지.** 작은 조각은 '기타'로 묶는다
- **하비볼은 명도가 아니라 채운 몫**으로 읽힌다. 0·1/4·1/2·3/4·1 다섯 단계
- **벤은 투명도 겹침**으로 교집합을 만든다. 원은 3개까지
- **밝은 회색에 흰 글자를 얹지 않는다.** `onTone()`이 배경 명도로 글자색을 고른다
- 그라데이션·3D·베벨은 쓰지 않는다
